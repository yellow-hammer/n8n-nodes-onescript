# Журнал изменений

Все заметные изменения в этом проекте будут задокументированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и этот проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [0.2.0] - 2026-10-11

- Добавили режим приложения Осени с одним процессом oscript, передачу сценария ключом -c и желудь из редактора ноды


### Документация

- Добавили политику сообщений об уязвимостях


### Обслуживание

- Добавили поддержку редактора HTML для идентификаторов в OneScript.node.ts, чтобы не ловить ошибку синтаксиса
